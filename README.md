# Student Performance & Enrollment Analysis

## Project Overview
This project analyzes student performance and course enrollment data using Microsoft Excel and Power BI.

## Tools
- Microsoft Excel
- Power BI
- GitHub

## Dataset
- 20 Students
- 8 Courses
- 40 Enrollments
- 40 Performance Records

## Key Results
- Total Students: 20
- Total Enrollments: 40
- Completed: 30
- In Progress: 10
- Completion Rate: 75%
- Average Final Score: 88.98
- Average Attendance: 90.78%
- Average Assignment Score: 86.80

## Power BI Dashboard
The Power BI project contains three pages:

1. Overview Dashboard
2. Course Performance
3. Student & Enrollment Analysis

## Excel Analysis
The Excel workbook contains:
- Student data
- Course data
- Enrollment data
- Performance data
- Analysis metrics
- PivotTables
- Dashboard visualizations
